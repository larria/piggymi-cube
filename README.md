# CFOP 魔方教学系统

基于 **three.js** 的三阶魔方 CFOP 教学 Web 应用。支持多端交互、任意状态智能求解、公式步进动画演示。

## 功能

- **3D 魔方渲染**：three.js 构建的 27 cubelet + 圆角贴纸，WCA 标准配色（白U 黄D 绿F 蓝B 红R 橙L——内部以面字母表示，白十字在 D）
- **多种操作方式**
  - 拖拽空白处 / 右键拖拽：旋转视角（轨道相机）
  - 拖拽魔方表面：raycast 命中贴纸，按拖拽方向智能判定转动的层与方向
  - 触摸：单指拖拽（同鼠标），双指捏合缩放
  - 滚轮缩放
  - 国际标准指令输入：`U D L R F B` + 后缀 `'` / `2`（如 `R U R' U' F2`）
  - 移动端 18 键操作面板
- **CFOP 智能求解**（从任意合法状态）
  - **Cross**：逐棱 BFS 求解（每棱 ≤7 步最优）
  - **F2L**：逐槽求解 —— 反向投影 BFS 预计算查表（每槽两面/三面族表，O(1) 查询）+ 分块 setup + 投影 BFS 兜底
  - **OLL**：2-look OLL 标准公式库 + 原子公式 BFS（深度 ≤3）
  - **PLL**：2-look PLL 标准公式库 + 原子公式 BFS（含 AUF 前后转）
  - 「下一步提示」：按当前阶段给出下一个教学步骤（单棱/单槽/整阶段公式）
  - 「自动演示」：完整 CFOP 分阶段动画还原，公式浮层高亮当前步
- **教学辅助**：阶段进度面板、每步公式说明、计时器、步数统计、撤销、打乱

## 快速开始

```bash
cd CFOP
python3 -m http.server 8642
# 打开 http://localhost:8642
```

> three.js（v0.160）已内置于 `lib/three.module.js`，无需 npm 安装。任意静态服务器均可。

    ├── core/
    │   ├── cube.js         # 魔方逻辑模型：54 贴纸、转动环、指令解析、M/E/S 切片

## 技术要点

- **状态模型**：54 facelet 一维数组，转动以置换环表示（由 3D 坐标旋转推导，经群论恒等式测试：`R⁴=e`、`(R U R' U')⁶=e`、打乱+逆=还原等 60+ 用例）
- **F2L 查表**：从还原态反向 BFS 生成「目标块位姿 + 受影响十字棱」投影签名表（每槽 ~85k 状态），运行时 O(1) 查表；两面族表（如 `{R,U}`）天然不碰对侧邻槽，避免逐槽求解时的互相破坏
- **性能**：搜索用 `moveFA(face, amount)` 直调（跳过正则）+ apply-undo 模式（无 clone）+ 投影签名去重
- **求解可靠性**：Node 端 60 用例全随机打乱回归测试，两轮 30/30 通过

## 颜色约定

白十字在 **D（下）**，黄在 **U（上）**，前 F=绿、右 R=红（WCA 标准）。
